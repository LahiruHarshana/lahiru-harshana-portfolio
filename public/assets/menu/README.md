# Menu Preview Images

Add your section preview images to this folder with the following names:

- `home-preview.jpg` - Screenshot of your Hero/Home section
- `about-preview.jpg` - Screenshot of your About Me section
- `services-preview.jpg` - Screenshot of your Services section
- `portfolio-preview.jpg` - Screenshot of your Portfolio/Work section
- `blog-preview.jpg` - Screenshot of your Blog section
- `contact-preview.jpg` - Screenshot of your Contact section

## Recommended Image Specifications:
- **Aspect Ratio:** 4:3
- **Size:** 400x300 pixels (or similar)
- **Format:** JPG or PNG
- **Quality:** Optimized for web (compressed)

## Quick Way to Create These:
1. Run your website locally
2. Take screenshots of each section
3. Crop to 4:3 aspect ratio
4. Save with the filenames listed above

Alternatively, you can modify the `SlideMenu.tsx` component to use different image paths.
